单端专线 一台境外机，但入口走国内 BGP，给的是国内入口 IP 客户端直连入口 IP → 商家内网 → 境外出口
双端专线 国内中转 + 境外落地两台 自己在中转机上配端口转发 / iptables DNAT
纯内网 只有境外机，国内段自己解决 自己再搭国内中转（成本不会比双端低）

步骤 1 · 买完先确认入口 IP 是不是国内的

ping <入口IP>                 # 国内 IP 段、延迟 <20ms 才对
traceroute <入口IP>           # 前几跳不该出现境外节点
curl -s https://ipinfo.io     # 出口显示香港，说明落地在港、入口在国内

ping 直接就是 50ms+ 的香港公网地址，说明你买的是普通香港 VPS，没走专线。

步骤 2 · 系统准备 + 开 BBR（Debian 12）

apt update && apt -y install curl socat
echo "net.core.default_qdisc=fq" >> /etc/sysctl.conf
echo "net.ipv4.tcp_congestion_control=bbr" >> /etc/sysctl.conf
sysctl -p
