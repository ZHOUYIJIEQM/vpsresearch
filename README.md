# VPS 选型清单（科学上网向）

面向「买 VPS 搭梯子」这一件事的选型资料，数据核实日期 **2026-11-26**。

## 内容

- **按线路选**：从 IPLC/IEPL 专线到普通国际绕路，六个档次逐级往下，每档一张表，只放有货且值得买的套餐
- **按商家看**：19 家商家各自全部套餐合并成一张表，按价格排序
- **推荐**：四套从 $15.98/年 到 $299.99/年 的具体购买方案，含详细优缺点
- **海外大厂 / 避雷 / 速查**：Vultr、DO、Hetzner 等基线价，已验证有问题的商家，按需求的速查结论

## 几点说明

- **有货状态**：`✅ 有货` 是实际打开产品页确认能下单的；`⚠️ 以链接页为准` 是官网有 Cloudflare 或跳转页抓不到实时库存，不等于没货
- **流量口径**：分单向 / 双向 / 未明确三态。**双向计算的商家，标称 1TB 当梯子用只有约 500GB**
- **带宽换算**：`60 Mbps` 是 60 兆比特每秒，约 7.5 MB/s
- **价格**：统一折成 USD/月 便于横向比价，CAD≈5.2 CNY、USD≈7.2 CNY，季付÷3、年付÷12
